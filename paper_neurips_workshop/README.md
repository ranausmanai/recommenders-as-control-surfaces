# NeurIPS 2026 Workshop Paper

Primary target: Foundations of Language Model Security (FLMSec).

Build:

```bash
tectonic paper.tex
```

The submission copy uses the official `neurips_2026.sty` with the
`dblblindworkshop` option and the FLMSec workshop title. The content limit is
eight pages excluding references.

Files:

- `paper.tex`: anonymous workshop manuscript
- `paper.pdf`: compiled review copy
- `references.bib`: self-contained bibliography
- `figures/paper_fig8_audit_validation.pdf`: main result figure
- `SUBMISSION_METADATA.md`: OpenReview title, abstract, keywords, and checks
